# PokéPlay

SPA web de Pokémon creada con **HTML + TailwindCSS (CDN) + JavaScript modular**, consumiendo **PokeAPI** y lista para deploy estático.

## Funcionalidades
- Listado principal con imagen, nombre, número, tipos, búsqueda y filtro por tipo.
- Vista detalle con stats en barras, habilidades y captura en `localStorage`.
- Modo batalla con selección de Pokémon, rival aleatorio, animación y sonido.
- Mi Pokédex con colección capturada y eliminación.
- UI responsive, modo oscuro, skeleton loading, lazy loading y microinteracciones.
